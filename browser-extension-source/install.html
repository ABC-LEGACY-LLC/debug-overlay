Debug Overlay — installer

This page carries the whole extension inside itself and needs no command prompt — it works even where administrators disable cmd. The browser reserves two clicks for you; everything else happens here.

Step 1 — write the files.
Press the button, then create or choose a permanent folder — for example a new folder called debug-overlay-extension in your Documents. Not Downloads: the browser will read this folder forever.

Step 2 — open the extensions page.
A web page is not allowed to open it for you. Copy the address and paste it into the address bar:

chrome://extensions (Edge: edge://extensions)
Step 3 — the two clicks the browser requires from a human.
On that page: switch ON Developer mode (top-right), press Load unpacked, and select the folder from Step 1.
Then open any website and press Alt+Shift+D.
Optional, once — one-press future updates.
Extension's Details → Extension options → Choose install folder… → select the same folder → Allow. From then on updates are a single press inside the overlay.
