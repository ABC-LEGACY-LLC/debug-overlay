2 Update

Fetches the new version's files from the repo and writes them into your install folder. It does not delete anything and does not restart the extension — you press ↻ on chrome://extensions afterwards, and this page tells you when.

Repair rewrites every current file — use it if the extension misbehaves or an update was interrupted. It never needs a newer version to exist.

Updates come only from this extension's own repository, only over HTTPS, and only when you press the button — never silently. Everything is fetched first and written only when all of it arrived, so an interrupted download cannot leave a half-written install.
